# 현실용음악학원 출석부

학원 출결·수납·원생 관리를 위한 웹 프로그램입니다. 지금은 디자인 시안 단계입니다.

## 시안 보기
아래 파일을 내려받아 브라우저(크롬, 엣지)로 열면 됩니다.

| 파일 | 내용 |
|---|---|
| `design/attendance.html` | 출석부 화면 시안. 날짜 칸을 누르면 수업 → 결석 → 보강 → 연기 → 입금(₩) 순서로 바뀝니다 |
| `design/records.html` | 기록 패널 시안 (누가 언제 무엇을 처리했는지) |
| `design/records.png` | 기록 패널 이미지 |
| `prototype/spreadsheet-demo.html` | 첫 시연판: 엑셀형 표와 엑셀 내보내기 |
| `prototype/sample-export.xlsx` | 엑셀 내보내기 샘플 |

시안에 나오는 이름과 전화번호는 모두 가짜 샘플입니다.

정한 규칙과 디자인 기준은 `CLAUDE.md`에 정리되어 있습니다.
